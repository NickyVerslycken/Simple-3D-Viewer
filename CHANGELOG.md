# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-23

First public release.

### Added
- Viewer for STL (binary and ASCII), OBJ (+ MTL colors), 3MF, PLY, AMF, GLB/glTF, FBX and Collada files.
- Free rotation, pan and zoom, standard views, fit to window.
- Zoom in / out with a percentage readout (100% = model fits the window), via buttons, keys and the View menu.
- Single color, per-part colors and colors from the file.
- Solid, edges, wireframe, x-ray and normals display modes; smooth and flat shading.
- Background colors, ground shadows, measured grid, axis indicator, Z-up toggle.
- Previous / next model in the same folder, PNG screenshots, drag and drop, "Open with" support.
- Windows installers (`.exe`, `.msi`) and a macOS disk image; file associations for all supported formats.
- Help menu with About, license and third-party notices.
